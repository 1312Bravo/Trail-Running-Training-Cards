# Lydiard Summary

## Status

**In development.** This is our documented interpretation of the Lydiard Method as presented by the Lydiard Foundation. It is not official Lydiard material and does not yet make `lydiard` active for card authoring.

## In Brief

Lydiard is a foundational running system built around substantial aerobic development, feeling-based effort, response-regulated recovery, sequential training phases, and backward timing from a goal. Its central argument is that later strength, anaerobic, and race-specific work should be built on an earned base rather than used to bypass it.

## Main Emphases

- Build aerobic capacity at the rate the whole runner can absorb.
- Treat the base as a durable resource throughout preparation, not a discarded opening phase.
- Develop the runner's internal judgement alongside external metrics.
- Regulate the next stress through recovery response.
- Build energy systems in sequence and integrate them before racing.
- Use backward planning to give each phase a reason and avoid rushed specificity.

## What It Does Not Mean

- It does not prescribe one mileage target or only long slow running.
- It does not make a hill session Lydiard merely because it is uphill.
- It does not automatically cover trail technique or mountain-specific demands.
