# Session Prompt

Add this after `COMMON.md` for a Session card.

```text
Visual class: Session action.

Create a precise, dynamic avatar with one clearly readable action or directional gesture. The composition should be lean and economical, with no extra detail beyond what explains the species and movement. It must remain recognisable at 96 pixels wide. Do not include the Session stopwatch symbol; the app renders that separately.
```

Session avatars resemble other Session avatars through focused movement and the amber accent. They remain stable when the same session belongs to multiple Micro cards.
