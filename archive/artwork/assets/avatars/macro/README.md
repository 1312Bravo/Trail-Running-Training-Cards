# Macro Avatar Prototypes

This folder contains archived Macro line-avatar examples. They are not connected to the app.

## Macro Master Rule

Macro avatars are the master reference for the Macro visual class. Each must show an immediately recognisable species silhouette and its key anatomical features while staying sparse enough for a white card. Mezzo, Micro, and Session cards use their own planning-level prompt and card-specific animal; they do not inherit species or anatomy from Macro cards.
