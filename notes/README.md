# Notes

This folder holds durable project notes. Keep each file focused so workflow, schema, and product planning do not duplicate each other.

## File Ownership

- `cloud_library_storage_workflow.md`: Google Drive storage, local cache, upload/download commands, bundle generation, and Python authoring helper workflows.
- `schema_design_and_validation.md`: card classes, fields, references, pathway validation, registry behavior, display config, and session workout structure.
- `card_library_rebuild_workflow.md`: deliberate full-library replacement, including safeguards for deleting obsolete Drive files.
- `product_backlog.md`: future product, app, and workflow ideas that are not active implementation rules.

## What Does Not Belong Here

- Card taxonomy and coach review decisions belong in `training_cards/cards/card_matrix.md`.
- Coaching philosophy and source interpretation belong in `coaching/`.
- Current project progress and next steps belong in `PLAN.md`.
