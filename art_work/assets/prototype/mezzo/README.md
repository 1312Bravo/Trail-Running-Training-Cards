# Mezzo Avatar Prototypes

These are early transparent SVG candidates. The first test is `mezzo_002`, the Endurance Development Block, as an independent alpine chamois using the shared line system and the Mezzo visual class.

Future Mezzo avatars use `art_work/prompts/COMMON.md`, `art_work/prompts/MEZZO.md`, and their own card-specific brief; they do not inherit Macro anatomy.
