# Session Prompt

Add this after `COMMON.md` for a Session card.

```text
Visual class: Session action.

Create a precise, dynamic avatar with one clearly readable action or directional gesture. The composition should be lean and economical, with no extra detail beyond what explains the species and movement. Place one warm-amber stopwatch silhouette behind or beside the avatar at restrained but clearly visible opacity. It must remain recognisable at 96 pixels wide.
```

Session avatars resemble other Session avatars through focused movement and the amber accent. They remain stable when the same session belongs to multiple Micro cards.
